# PopupMessenger

LAN 팝업 메신저 (xpopup 스타일). Tauri 2 + 순수 HTML/JS, 트레이 상주형.

## 빌드

```bash
npm install
npm run dev      # 개발 실행
npm run build    # 설치 파일 (Windows: MSI/NSIS, macOS: .app/.dmg)
```

필요: Rust (stable), Node.js. Windows는 WebView2, macOS는 Xcode Command Line Tools. 지원 OS: Windows 10/11, macOS 15 Sequoia ~ macOS 27.

## 동작 방식

| 항목 | 내용 |
|---|---|
| 포트 | 55000부터 TCP·UDP가 모두 비어 있는 첫 포트(55000+a, 최대 65500)를 사용. 한 PC에서 여러 개 실행해도 1씩 증가 |
| 탐색 | UDP로 각 인터페이스의 브로드캐스트 주소 × 포트 55000~55000+N(기본 10)에 질의, 30초마다 반복. 응답에 ID·이름·호스트·포트·알림 여부·첨부 한도·디스크 여유·상태·프로토콜 버전(현재 3) 포함. 95초 무응답이면 오프라인 |
| 메시지 | 상대 포트로 TCP 연결 → JSON 헤더 → 수락/거절 → 파일 원본 스트리밍 → 완료 |
| 알림 켬 | 수신 즉시 항상 위 팝업 창 |
| 알림 끔 | 받은 쪽지함에만 쌓이고 트레이 아이콘에 작은 빨간 점 (아이콘 색은 항상 상태: 파랑 온라인 / 보라 방해금지 / 회색 오프라인) |
| 이름 | 기본 이름(OS 계정 이름)이 네트워크의 다른 사용자와 같으면 자동으로 `이름-xxxx`(컴퓨터 이름 해시 4자리)로 바뀌어 저장. 직접 바꿀 때는 네트워크에 이미 있는 이름은 쓸 수 없음. "컴퓨터 호스트 이름 보기"(기본 끔)가 꺼져 있으면 이름이 같은 상대는 목록에 `이름-xxxx`로 표시 |
| 상태 | 트레이 "상태" 메뉴: 온라인 / 방해금지 / 오프라인. 오프라인이면 다른 사람 목록에서 사라짐. 방해금지면 보내는 사람에게 표시되고, 받을 때 팝업·수신 중 창 없이 쪽지함에 쌓이며 트레이 아이콘에 작은 빨간 점. "재시작 시 온라인으로 자동 전환"(기본 켬) |
| 트레이 | 좌클릭·우클릭 모두 같은 메뉴: 상태 → 전송 그룹(접속 중인 그룹원이 있는 그룹만) + "전송 그룹 관리…" → 자주 보낸 순 상위 10명(클릭 시 바로 쪽지 쓰기, 11명 이상이면 "더보기…") |
| 연락처 검색 | 트레이 "연락처 검색…": 오프라인 사용자까지 찾아 바로 쪽지 쓰기. 릴레이가 있으면 LAN + 릴레이 연락처(서버가 "검색" 정책이면 사용자 이름·계정 ID 정확히 입력 시 서버에서 조회), 없으면 LAN + 주고받은 기록에서만 |
| 전송 그룹 | "전송 그룹 관리…"에서 그룹 만들기·편집·삭제·보내기. 오프라인 사용자도 넣을 수 있고, 사용자 ID로 저장되므로 이름이 바뀌어도 유지. 오프라인이면서 LAN·릴레이 연락처에 없는 사용자는 [−]로 목록과 모든 그룹에서 지울 수 있음. 그룹으로 보낼 때는 접속 중인 그룹원에게만 전송. "그룹 이름과 다른 받는 사람 공개"를 켜면(CC), 0.1.4 이상(프로토콜 3)인 받는 사람의 쪽지에 그룹 이름과 함께 받은 사람이 표시되고 "전체 답장" 가능. 끄면(BCC) 각자 단독으로 받은 것처럼 보임 |
| 첨부 | 기본 10개 · 파일당 10GB. 받는 쪽 설정으로 조정 가능하며 디스크 여유(−512MB)를 넘지 않도록 자동 축소 |
| 대량 수신 | 3개 이상 또는 20MB 이상이면 "수신 중" 창(진행률, 취소) |
| 폴더 | 쪽지 쓰기 창에 파일·폴더를 끌어다 놓거나 우클릭 메뉴로 첨부. 폴더를 첨부하면 보낼 때 `<폴더>.zip`으로 자동 압축 (링크·`.DS_Store` 제외, 보낸 뒤 임시 파일 삭제) |
| 받은 파일 | 기본은 쪽지마다 `보낸 사람 YYYY-MM-DD HHMMSS` 폴더를 만들어 저장. 설정에서 끄면 저장 위치에 바로 저장 |
| 메모리 | 효율 모드(기본): 창을 닫으면 해제. 성능 모드: 숨은 창 하나를 미리 그려 두어 창이 바로 뜸 |
| 자동 실행 | 릴리스 빌드에서 로그인 시 자동 실행 등록 (설정에서 끔) |
| 우클릭 메뉴 | Windows: 탐색기에서 파일·폴더 우클릭 `Send using PopupMessenger` (HKCU, 관리자 권한 불필요. Windows 11은 "추가 옵션 표시" 안). macOS: Finder 우클릭 > 빠른 동작 `Send using PopupMessenger` (`~/Library/Services`에 설치) |

데이터: 앱 데이터 폴더의 `settings.json`, `data.json`. 받은 파일: `다운로드/PopupMessenger` (설정에서 변경).

## 릴레이 서버

외부망 중계와 오프라인 보관 후 전달을 위한 선택적 셀프호스팅 서버가 [`relay/`](relay)에 있습니다 (Docker, 관리자 웹 UI). 프로토콜: [docs/relay-protocol.md](docs/relay-protocol.md).

| 항목 | 내용 |
|---|---|
| 연결 | 설정 창 맨 아래 "릴레이 서버 계정" > "릴레이 서버 연결…": 주소 → 서버 정보·인증서 지문 확인 → 로그인 / 가입 신청 (계정 없는 서버는 기기 등록) |
| 인증 | 비밀번호는 저장하지 않음. 기기가 계정에 등록되면 서버별 기기 비밀값으로 자동 로그온. 자체 서명 인증서는 처음 확인한 지문으로 고정 |
| 경로 | LAN에서 보이면 LAN 직접. LAN 연결 실패·상대 오프라인·서버의 경유 강제 정책이면 릴레이. 오프라인이면 릴레이에 보관했다가 상대가 접속하면 자동 전달 |
| 목록 | 릴레이 연락처는 받는 사람 목록에 함께 표시 (같은 사람이 LAN에 보이면 하나로). 오프라인 연락처도 "보관 전달"로 선택 가능, 그룹에도 포함 |
| 암호화 | 서버 정책이 종단간 암호화면 X25519 + XChaCha20-Poly1305로 본문·파일을 암호화. 상대 키가 바뀌면 설정에서 확인할 때까지 보내지 않음 |

개발용: `POPUPMESSENGER_PROFILE=<이름>`으로 실행하면 별도 데이터 폴더(`…\com.popupmessenger.app.profile-<이름>`)와 포트 47000부터를 쓰는 테스트 인스턴스가 뜹니다 (단일 인스턴스·자동 실행·우클릭 메뉴 등록 없음). `POPUPMESSENGER_CDP_PORT=<포트>`를 함께 주면 WebView2 원격 디버깅 포트를 엽니다.

## 참고

- 처음 실행 시 Windows 방화벽 허용 창이 뜨면 "개인 네트워크"를 허용해야 다른 PC에서 보입니다.
- macOS: 처음 실행 시 "로컬 네트워크" 접근 허용 창에서 허용해야 탐색·전송이 됩니다 (시스템 설정 > 개인정보 보호 및 보안 > 로컬 네트워크). 다운로드 폴더 접근도 한 번 묻습니다.
- macOS: 빌드는 임시(ad-hoc) 서명이라 처음 열 때 Gatekeeper 경고가 뜹니다. Finder에서 우클릭 > 열기, 또는 `xattr -dr com.apple.quarantine /Applications/PopupMessenger.app`. 빠른 동작이 안 보이면 시스템 설정 > 키보드 > 키보드 단축키 > 서비스(또는 확장 프로그램 > Finder)에서 켜 주세요.
- macOS에서는 Dock 아이콘 없이 메뉴 막대(트레이)에만 표시됩니다.
- 브로드캐스트가 막힌 망(서브넷이 다른 경우 등)은 설정의 "추가 탐색 주소"에 상대 IP를 넣으면 됩니다.
- 전송은 암호화되지 않습니다. 신뢰할 수 있는 LAN에서만 사용하세요.
- `src-tauri/icons`의 아이콘은 빌드용 임시 파일입니다. 트레이 아이콘은 코드에서 그린 점입니다.
